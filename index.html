ChatGPT + OpenCode

A secure path to your local coding agent.

PickleShell connects ChatGPT to a locally operated OpenCode agent through an outbound-only Secure MCP Tunnel. Your Gateway stays off the public Internet.

View the repository Deployment guide

How it works

The public interface is an MCP tool. The local Gateway is authenticated, workspace-scoped, and reachable only inside the trusted environment.

Built for controlled local work

Session continuity

Continue an OpenCode conversation with an explicit session_id.

Operator control

Choose workspaces and models from an allowlist you control.

Small file transfer

Transfer up to 20 files with size, destination, overwrite, and path checks.

Parallel sessions

Independent sessions run in parallel; a duplicate explicit session receives an immediate busy response.

Security boundary

PickleShell is a trusted single-operator bridge, not an anonymous public shell. Use a dedicated unprivileged service account and keep credentials outside the repository.
