⚙️ Capabilities

What you can do with PickleShell

A focused set of features designed for controlled, single-operator local work.

Session Continuity Core

Pick up an OpenCode conversation with an explicit session_id. No context lost between calls.

Model Selection Controlled

Choose models only from an operator-controlled allowlist. No surprises, no rogue endpoints.

File Transfer Safe

Transfer up to 20 files per request with size, destination, overwrite, and path traversal checks built in.

Workspace Scoping Scoped

All file operations stay within the configured workspace. No accidental writes to /.

Parallel Sessions Concurrent

Independent sessions run in parallel. Duplicate explicit sessions get a clean busy response.

Operator Control Governed

Workspaces and models are operator-selected allowlists, not open menus. The human stays in the loop.

🛡️ Security

A secure bridge, not a public shell

PickleShell is a trusted single-operator bridge, not an anonymous public service. Deploy with a dedicated unprivileged service account and keep credentials outside the repository.

  • ✓ No inbound port forwarding or public endpoint
  • ✓ Outbound-only tunnel from your local machine
  • ✓ Operator-controlled workspaces and model allowlists
  • ✓ Path, symlink, and overwrite protection on file transfer
  • ✓ Authenticated requests and auditable local execution
// Every request follows this path ChatGPT → outbound Secure MCP Tunnel → authenticated Gateway → model allowlist check → workspace-relative file boundary → OpenCode // No inbound ports. No public IP. No surprises.
