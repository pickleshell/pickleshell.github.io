Important audit limitation.

Audit found reference path matches in 55/155 traces and hidden path matches in 25/155. Hidden/reference artifacts were available in shared Git history, so this was not a blind benchmark. Results are published as historical/provisional evidence, not a claim of blind evaluation.

Expert-review policy.

GPT-5.6 Sol is the single canonical expert reviewer to keep review costs controlled. Independent Gemini cross-checks broadly agreed with its scoring. Claude Opus 4.8 was removed from future judging after repeatedly missing seeded hidden defects while evaluating candidate patches. The complete review data, submitted patches, test results, and pipeline are public for independent verification.
