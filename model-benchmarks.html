Methodology

How a benchmark result is produced

Every route follows the same controlled path. A failure stays visible as evidence; it is not converted into a quality score or silently removed from the table.

  1. 01Freeze releaseTask, roster, checks, and allowed files are fixed.
  2. 02PreflightA harmless hi request confirms the exact route.
  3. 03One clean attemptFresh workspace, agent home, and session for every model.
  4. 04Verify patchAllowed paths, public tests, and objective checks run separately.
  5. 05Review evidencePatch, timing, cost, and outcome are frozen; reviews remain separate.
  6. 06Publish manuallySanitized evidence and checked tables are reviewed before release.

One attempt. No second chance. Retries cost time and money; the first delivered result is the one preserved and scored. Read the full workflow ↗
